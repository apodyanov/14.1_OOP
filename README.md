# Введение в ООП
## Задание
### В рамках этих домашних заданий мы проработаем использование классов и объектов на основе популярной темы e-commerce. E-commerce  — электронная торговля, или электронная коммерция. На данном этапе работы мы не будем реализовывать систему платежей, однако подготовим всё для того, чтобы у нас появилось ядро для интернет-магазина. В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.
